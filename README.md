# Python for Everybody — Course Projects

This repository contains the hands-on projects and exercises developed while studying the **Python for Everybody** specialization. It is organized into two courses that build from Python fundamentals to working with core data structures.

## Overview

The repository is designed as a learning portfolio showcasing practical Python programs created during the specialization. Each chapter includes a short project or exercise that demonstrates a specific programming concept.

## Courses

- **Course 01 — Getting Started with Python**
  - Covers variables, expressions, conditional logic, functions, and loops.
  - Includes beginner-friendly programs such as calculators, decision-making examples, and interactive scripts.

- **Course 02 — Python Data Structures**
  - Focuses on Python built-in data structures like strings, lists, and file handling.
  - Includes programs for text analysis, file processing, and list-based applications.

## Requirements

- Python 3.x

## Running the Scripts

From the repository root, run any script with Python. Example:

```bash
python course-01-getting-started-with-python/chapter-03-conditional-code/movie_recommender.py
```

Or use the chapter folder directly:

```bash
python course-02-python-data-structures/chapter-08-lists/library.manager.py
```
