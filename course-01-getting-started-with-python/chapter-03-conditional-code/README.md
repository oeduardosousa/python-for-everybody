# Movie Recommendation System
A Python program that recommends movies based on the user's age and favorite genre.

## Project Description
This project was created while studying the "Conditional Code" chapter from the Python for Everybody specialization.
The program asks the user for their age and preferred movie genre, then uses conditional statements to recommend a suitable movie.

## Concepts Practiced
- User input
- Variables
- Data type conversion
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Logical operators

## How It Works
The user provides:
- Age
- Favorite movie genre
The program analyzes the information and recommends a movie based on the conditions.
