# Movie Recommendation System

A Python program that recommends movies based on the user's age and favorite genre.

## Project Description

This project was created while studying the "Conditional Code" chapter from the Python for Everybody specialization. The program asks the user for their age and preferred movie genre, then uses conditional statements to recommend a suitable movie.

## Concepts Practiced

- user input
- variables
- data type conversion
- conditional statements (`if`, `elif`, `else`)
- comparison operators
- logical operators

## How It Works

The user provides:
- age
- favorite movie genre

The program analyzes the information and recommends a movie based on the conditions.

## How to Run

Run the script with Python:

```bash
python movie_recommender.py
```

## Example

If the user enters an age and a genre, the program may return a recommendation such as:

```text
Recommended movie: The Matrix
```
