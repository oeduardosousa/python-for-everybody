# Fitness Calculator

A Python program that calculates basic fitness information using custom functions.

## Project Description

This project was created while studying the "Functions" chapter of the Python for Everybody specialization. The program collects information from the user, such as weight, height, age, and exercise duration, then uses functions to calculate BMI, classify the user's weight category, and estimate calories burned.

## Concepts Practiced

- creating functions
- using function parameters
- returning values from functions
- storing and using variables
- collecting user input
- converting data types
- using conditional statements
- organizing code into reusable blocks

## How It Works

The user provides:
- weight in kilograms
- height in meters
- age
- exercise duration in minutes

The program calculates:
- body mass index (BMI)
- BMI category
- estimated calories burned during exercise

## How to Run

Run the script with Python:

```bash
python fitness_calculator.py
```

## Example

After entering the requested values, the program displays a summary of the user's fitness information, including BMI and estimated calories burned.
