# Fitness Calculator
A Python program that calculates fitness information using custom functions.


## Project Description

This project was created while studying the "Functions" chapter from the Python for Everybody specialization.
The program collects information from the user, such as weight, height, age, and exercise time, then uses functions to calculate BMI, classify the user's weight category, and estimate calories burned.


## Concepts Practiced

- Creating functions
- Function parameters
- Return values
- Variables
- User input
- Data type conversion
- Conditional statements
- Code organization


## How It Works

The user provides:
- Weight (kg)
- Height (m)
- Age
- Exercise duration (minutes)
The program calculates:
- Body Mass Index (BMI)
- BMI category
- Estimated calories burned during exercise
