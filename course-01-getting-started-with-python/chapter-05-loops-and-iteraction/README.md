# Quiz Game

A simple Python quiz game that uses loops and user interaction to ask questions and track the player's score.

## Project Description

This project was created while studying the "Loops and Iteration" chapter of the Python for Everybody specialization. The program presents a series of questions, collects the user's answers, and keeps score based on correct responses.

## Concepts Practiced

- using `while` and `for` loops
- collecting user input
- comparing answers
- updating scores during iteration
- controlling program flow with conditions

## How It Works

The game asks the player a set of questions and checks whether each answer is correct. The score increases whenever the player answers correctly.

## How to Run

Run the script with Python:

```bash
python quiz_game.py
```

## Example

The game may ask questions such as:
- What is the capital of France?
- Which planet is known as the Red Planet?

The player receives feedback after each answer and sees the final score at the end.
