# Course 02 - Python Data Structures

This folder contains the projects and exercises developed while studying the second course of the **Python for Everybody** specialization.

## About

This course focuses on Python's built-in data structures and how they can be used to organize, store, and manipulate data efficiently. The exercises in this course emphasize writing cleaner, more scalable programs while working with strings, lists, dictionaries, and other core data structures.

## Contents

This course includes practice and small projects such as:
- string manipulation exercises
- email analysis programs
- beginner-friendly Python scripts that demonstrate core concepts
