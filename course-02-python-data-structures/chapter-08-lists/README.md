# Chapter 08 — Lists: Library Manager

This folder contains a small interactive Python program that demonstrates how to use lists to store, search, and manage a collection of items.

## Project Overview

`library.manager.py` is a console-based Library Manager where the user can:
- add book titles to a library list
- view all current books
- search for a book by name
- remove a book from the library
- exit the program

The project is designed to reinforce Python list operations, user input handling, and basic control flow with loops and conditional statements.

## How to Run

From this chapter folder, run:

```bash
python library.manager.py
```

Then follow the menu prompts to interact with the library.

## Features

- Dynamic book list stored in memory
- Menu-driven interface for easy operation
- Search and removal operations using list membership
- Simple input validation for menu selection

## Notes

- The library contents are not saved after the program ends.
- Book titles are stored exactly as entered.
- This exercise is intended for learning and practice with Python lists.
